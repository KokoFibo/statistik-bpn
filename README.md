# Statistik E-Commerce Indonesia 2024 (BPS, rilis 2025)
Halaman: `/` (daftar laporan), `/ecommerce`, `/kesejahteraan`. Jalankan `npm install` lalu `npm run dev`.
Semua angka ada di `src/data/ecom.ts`; ubah di sana, halaman ikut berubah.
Untuk PDF berikutnya: salin pola `src/pages/index.astro` ke halaman baru dan buat file data baru.
